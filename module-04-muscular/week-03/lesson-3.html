🎯 BY THE END OF THIS LESSON YOU WILL BE ABLE TO…
1
I will be able to describe hypertrophy in cell-level terms: thicker fibers, more myofibrils, satellite cell donation of nuclei, not new fibers.
2
I will be able to describe at least three changes that endurance training produces and distinguish them from the changes produced by resistance training.
3
I will be able to name three settings in which atrophy occurs and explain which are reversible.
4
I will be able to describe sarcopenia and name the single most-effective evidence-based intervention.
