🎯 BY THE END OF THIS LESSON YOU WILL BE ABLE TO…
1
I will be able to describe myasthenia gravis, rhabdomyolysis, and tetanus, and name the exact point in the contraction chain each one disrupts.
2
I will be able to explain how a nerve agent like sarin causes flexion paralysis by disabling acetylcholinesterase.
3
I will be able to distinguish, at a category level, muscular dystrophy (a fiber-structure disease) from multiple sclerosis (a myelin disease).
4
I will be able to identify which specific muscles produce a set of everyday movements — the same skill the “Muscles in Motion” project asks you to demonstrate.
